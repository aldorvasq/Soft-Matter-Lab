# Soft Matter Lab
 Repository for simulation scripts and other miscellaneous objects.
 
 Here you may find some of the python, lammps, bash and lammps scripts I have created for my creating, running and analyzing my simulations. 

 This repository is still under development so some scripts may lack sufficient comments or explanation as to what they do. 

 When I write my scripts I try to make them asself-explanatory and universal as possible. Nevertheless, some where created without clarity in mind an a more practical approach. If you are reading this, chances are you know where and when to reach me, so please do so if you have any questions. 

 Feel free to contribute to this repository via a pull-request.
